This folder feeds the "A Visual Journey" gallery on the Blog page.

How to add/change/remove photos:
1. Drop image files here (jpg, jpeg, png, webp, or avif).
   - Keep each file under ~500KB and resized to about 1600px wide for fast loading.
   - Use simple lowercase filenames with no spaces, e.g. leopard-01.jpg
2. Delete a file to remove it from the gallery.
3. No code changes needed — the Blog page automatically shows whatever
   images are in this folder, in a floating grid layout.
4. Commit and push (or ask Claude to do it) so the change goes live.
