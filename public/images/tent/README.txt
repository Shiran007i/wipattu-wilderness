This folder feeds the room photo shown on the Booking page (the "Deluxe
Chalet" reference card with the rate grid).

How to add/change/remove photos:
1. Drop image files here (jpg, jpeg, png, webp, or avif) — any order, no
   naming required.
2. If you add more than one photo, they'll auto-rotate with a fade
   transition. One photo just displays as a static image.
3. Delete a file to remove it. No code changes needed.
4. Keep each file under ~500KB, resized to about 1200px wide.
5. Commit and push (or ask Claude to do it) so changes go live.
