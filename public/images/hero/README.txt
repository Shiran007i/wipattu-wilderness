This folder feeds the auto-rotating background carousel on the Home page Hero section.

How to add/change/remove photos:
1. Drop image files here (jpg, jpeg, png, webp, or avif).
   - Landscape/wide photos work best since this fills the full-width banner.
   - Keep each file under ~500KB and resized to about 2000px wide for fast loading.
   - Use simple lowercase filenames with no spaces, e.g. safari-01.jpg
2. Delete a file to remove it from the carousel.
3. No code changes needed — the Hero section automatically shows whatever
   images are in this folder, fading between them with dot navigation.
4. Commit and push (or ask Claude to do it) so the change goes live.
