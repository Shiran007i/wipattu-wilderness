This folder feeds the Food & Drinks page. Like the "services" folder, these
photos are NOT a random pool — each image is tied to a SPECIFIC section, so
the filename must match exactly.

Add a photo for each section using these exact filenames (any of jpg,
jpeg, png, webp, avif):

  sri-lankan-cuisine.jpg   -> "Authentic Sri Lankan Specialties" section
                              (e.g. rice & curry, hoppers, kottu roti)
  western-cuisine.jpg      -> "Refined Western & International Favorites"
                              (e.g. campfire BBQ, continental breakfast, pasta)
  beverages.jpg            -> "Wilderness Spirits & Refreshments" section
                              (e.g. chilled beer, wine, sundowners)

If a file is missing, that section keeps showing its current default
photo — nothing breaks. Keep each file under ~500KB, resized to about
1400px wide, for fast loading.

Commit and push (or ask Claude to do it) so changes go live.
