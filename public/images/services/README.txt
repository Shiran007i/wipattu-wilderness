This folder feeds the "Accommodation / Food & Beverage / etc." service
cards on the Home page. Unlike the other image folders, these photos are
NOT a random pool — each image is tied to a SPECIFIC card, so the
filename must match exactly.

Add a photo for each card using these exact filenames (any of jpg,
jpeg, png, webp, avif):

  accommodation.jpg      -> "Accommodation" card
  food-beverage.jpg      -> "Food & Beverage" card
  adventure.jpg          -> "Adventure & Experiences" card
  guest-services.jpg     -> "Guest Services" card
  recreation.jpg         -> "Recreation & Relaxation" card
  safety.jpg             -> "Safety & Sustainability" card

If a file is missing, that one card keeps showing its current default
photo — nothing breaks. Keep each file under ~500KB, resized to about
1200px wide, for fast loading.

Commit and push (or ask Claude to do it) so changes go live.
