This folder feeds the horizontal auto-scrolling photo strip near the
bottom of the Home page.

How to add/change/remove photos:
1. Drop image files here (jpg, jpeg, png, webp, or avif) — any order, no
   naming required.
2. Works well with 6-10 photos (they loop continuously).
3. Delete a file to remove it. No code changes needed.
4. Keep each file under ~400KB, resized to about 800px wide (these
   display fairly small).
5. Commit and push (or ask Claude to do it) so changes go live.
