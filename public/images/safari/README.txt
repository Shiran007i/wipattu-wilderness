This folder feeds safari/wildlife photos across the site: the Booking page's
main hero image, the Home page's Safari Highlight section, the Safari
Booking page's new photo gallery, and several other fallback spots
(Experiences, Focus Gallery, Scrolling Gallery, Wildlife Gallery, social
share previews).

TWO kinds of images go here:

1. ONE reserved, specifically-named file for the Booking page's main hero
   image (leopard, jeep, elephant — whatever best represents the property):

     booking-hero.jpg   (or .jpeg/.png/.webp/.avif)

2. ANY OTHER filenames — these become a general pool used for the Safari
   Highlight section, the Safari Booking page's new gallery display, and
   other rotating spots around the site. Add as many as you like, any
   names, e.g.:

     leopard-01.jpg
     jeep-safari-02.jpg
     elephant-herd-03.jpg

How to add/change/remove photos:
- Drop image files here (jpg, jpeg, png, webp, or avif).
- Delete a file to remove it. No code changes needed.
- Keep each file under ~600KB, resized to about 1600-2000px wide (these
  are used as large hero/background images in places).
- Commit and push (or ask Claude to do it) so changes go live.

Until real photos are added, these spots show a plain gradient/pattern
background instead of a stock photo, to avoid ever showing an
unintentional or mismatched image again.
