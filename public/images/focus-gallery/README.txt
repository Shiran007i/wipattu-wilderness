This folder feeds the interactive "click to expand" photo gallery on the
Home page (3 tall panels, click one to bring it into focus).

How to add/change/remove photos:
1. Drop image files here (jpg, jpeg, png, webp, or avif) — any order, no
   naming required.
2. Works best with 3 photos, but any number is fine.
3. Delete a file to remove it. No code changes needed.
4. Keep each file under ~500KB, resized to about 1400px wide.
5. Commit and push (or ask Claude to do it) so changes go live.
